# mushroom-classifer-app
Deep learning computer vision project to identify mushroom types using a mushroom images dataset.

- dataset: universe.roboflow platform srilankan-mushroom-species dataset
- type: image dataser
- files:
    - train
    - test
    - valid
Note: Dataset is not included in the repo. Please download it from the site
- pre trained model: MobileNetV3Small
